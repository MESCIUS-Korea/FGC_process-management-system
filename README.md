# Forguncy 프로세스 관리 데모

Forguncy(노코드 플랫폼)로 구현한 **업무 프로세스 관리** 데모입니다.
업무 단계별 진행 상황 추적, 담당자 배정 등 프로세스 관리 업무를 노코드로 구축한 예시를 확인할 수 있습니다.

## 🔗 데모 바로가기

👉 [데모 실행하기](https://demo.forguncy.co.kr/process)

## 📋 주요 기능

- 프로세스 단계별 진행 현황 관리
- 담당자/부서별 업무 배정
- 진행 상태 추적 및 알림
- 처리 이력 조회

## 💾 Forguncy 다운로드

이 데모는 MESCIUS Forguncy로 제작되었습니다. 직접 열어보거나 커스터마이징하려면 아래에서 Forguncy를 다운로드하세요.

👉 [Forguncy 다운로드](https://www.mescius.co.kr/forguncy/download)

## ℹ️ Forguncy란?

Forguncy는 코딩 없이 드래그 앤 드롭 방식으로 웹 애플리케이션을 만들 수 있는 MESCIUS의 노코드 개발 플랫폼입니다. 프로세스 관리, 인사평가, 재고관리, 결재 워크플로우 등 다양한 업무용 애플리케이션을 빠르게 구축할 수 있습니다.
